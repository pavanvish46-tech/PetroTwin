# PetroTwin AI Frontend

React 18 + Vite frontend for the SIH 26120 FastAPI backend.

## Run locally

```powershell
npm install
$env:VITE_API_BASE_URL="http://127.0.0.1:8000"
npm run dev
```

The UI includes login, dashboard, wells, Digital Twin what-if simulation, predictions, optimization, recommendations/approval, alerts and reports views.
